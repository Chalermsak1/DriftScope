# Development decisions, failures, and corrections

This is a development record. The authoritative final validation is `tests_final.xml` and `verification.json`. Earlier test XML/logs are deliberately retained and do not describe the final state.

1. **Preservation boundary.** Created a separate `research/conventional` module on `research/representative-cohort`. Snapshotted the 139 pre-existing local project files. The original 31-file experiment manifest and eight-file approved-plan manifest remain valid. Old pilot records are unchanged after integration testing.

2. **Independent coverage reference.** Implemented signed per-drift support and disjoint tile ownership with read halos. Scalar enumeration checks masks, scores, and physical paths independently of the production support helper. Original-fixture evaluated paths increased from 390,404 to 489,730. The drift-specific physically invalid edge triangles remain outside the search.

3. **Cadence association failure in unit tests.** The initial synthetic global-chirp test recovered only two of three ON pieces in one association. A short scan's strongest local representative had a slope farther from the true slope than its grid spacing suggested, despite a compatible local frequency path. Replaced the grid-only slope gate with intersection of all timestamped endpoint corridors. The failed XML records are retained. The tolerance was not enlarged to force recovery.

4. **Initial calendar frame.** A fixed seven-day C-band metadata query was empty. This was retained as an access result, not interpreted as an absence of observations elsewhere. A separate fixed 2018 calendar feasibility query returned 102 rows. No spectral or detector outcome informed those queries.

5. **Metadata cadence ambiguities.** Initial name/time pattern matching yielded 27 sequences in six linkage components. Ten sequences could treat a repeated `_OFF` pointing as the primary target in a shifted alternating window. Explicit OFF-primary rejection left 17 metadata proposals; the earlier intermediate frame is retained.

6. **Case-sensitive source-name mismatch.** The first header-only AND_X source probe passed timestamp, pointing, shape, telescope, and resolution checks but rejected all six source names because the archive used `AND_X`/`AND_X_OFF` and headers used `And_X`/`And_X_off`. Added trim/casefold identifier matching while retaining the original strings and requiring independent coordinate agreement. The original failed probe is retained as `cohort_header_probe_case_sensitive.json`.

7. **Real pointing-integrity failure.** The corrected AND_X probe passed individual archive/header correspondence but failed the inherited one-arcsecond ON-consistency criterion: repeated ON coordinates differed by approximately 1.67 and 2.31 arcseconds from the first. This does not establish bad telescope data. The one-arcsecond threshold is a conservative inherited engineering assumption, not an instrument-validated C-band beam criterion. The failure remains in `cohort_header_probe_pointing_failure.json`.

8. **Metadata geometry amendment before waveform access.** Applied the same ON/OFF geometry checks to metadata proposals before sampling. The final frame has two accepted proposals and 25 rejected sequences, with reasons and separations retained. It has two independent components, below the planned access and main-study group targets. No detector output or sensitivity outcome informed these corrections. The selected AND_XI proposal then passed all six actual source-header and cadence-integrity checks. The successful probe accessed 393,216 range bytes; no scientific spectral array was read. Each probe execution was independently limited to 48 MiB; its successful counter is not a claim about all cumulative network traffic.

9. **First full experiment aborted on an invalid recovery assignment.** Strict JSON writing rejected an infinity while saving the intermittent cadence case. Investigation found that a truth with no active samples had equal real/dummy assignment costs, allowing a spurious match to an unrelated event with infinite path error. Invalid real pairs now start above the unmatched penalty, including when active support is empty. Added an explicit regression test. Kept the failed log and local partial outputs under ignored `results/failed_attempts/initial_no_active_support_assignment`; they are not the validated reference.

10. **Output and environment improvements.** Cadence case records now save individually before the combined table, reducing evidence loss on later failure. Matplotlib/font caches are placed in the writable project cache before import. Plotting warnings from the initial attempt remain in that log; no installed dependencies or original scientific files were changed.

11. **Final execution.** Completed the coverage/regression audits, 80-line synthetic stress case, Gaussian integration convergence checks, 48 randomized continuous-linear development trials, and four real-cadence engineering cases. Generated the full six-family design without claiming to execute it. Source/data/score hashes and explicit stage outcomes were recorded.

12. **Full regression QA and repeat.** Ran all original baseline/pilot and new conventional tests: 115 passed, zero failures/errors/skips. The historical offline archive test temporarily regenerated pilot evidence/excerpts; these were backed up/restored and the full preservation snapshot was checked. A complete new experiment repeat matched all 17 stable scientific JSON records, including exact array hashes. A supplementary paired-line challenge was executed twice identically and recovered both signals under both the old and new arms; no improvement is claimed for that case.

The representative source-sample cohort, instrument-justified geometry, conditional-placement uncertainty, established-comparator calibration, production-scale search, and locked evaluation remain open work. No LLM, origin claim, or population sensitivity conclusion was introduced.
