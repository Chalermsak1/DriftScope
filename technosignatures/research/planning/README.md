# Research planning package

Prepared 19 November 2026. This package defines future work; it does not claim that the proposed cohort, sensitivity study, models, or human-review study have been executed.

Read in this order:

1. [Research plan](../../docs/RESEARCH_PLAN.md): objective, scientific scope, current gaps, methods, milestones, resources, risks, and decisions.
2. [Statistical analysis plan](../../docs/STATISTICAL_ANALYSIS_PLAN.md): populations, denominators, split construction, matching, uncertainty, sample-size reasoning, and primary endpoints.
3. [Literature and novelty register](../../docs/LITERATURE_AND_NOVELTY.md): verified primary sources, interpretation limits, and the related-work lead still requiring verification.
4. [Execution backlog](../../docs/RESEARCH_EXECUTION_BACKLOG.md): ordered tasks and scientific tests.
5. [Machine-readable study plan](study_plan.json): proposed numerical defaults and status.
6. [Planning calculations](planning_calculations.json): arithmetic checked from the existing result and explicit statistical formulas; these are not new empirical performance measurements.

The original code, `run_001`, original project manifest, and original ZIP are preserved unchanged. The next phase requires a separate research implementation/configuration series.

The planning-package manifest records checksums for these documents and numerical planning artifacts. The downloadable research ZIP includes this plan plus the existing experiment, source, and saved results. It excludes the virtual environment, caches, and redundant repeat-run arrays.
